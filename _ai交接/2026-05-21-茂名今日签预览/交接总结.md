# 交接总结

## 完成内容
- 新增「茂名今日签」本地测试页面，用于预览每日首页效果
- 页面结构：今日签主卡片 + 天气嘴替 + 指数区 + 宜忌区 + 幸运信息 + 测试入口 + 换嘴替按钮
- 所有内容基于日期 seed 生成，同一天刷新保持稳定，次日自动变化
- 天气状态用日期 seed 模拟（热/雨/阴/闷/风大），不接真实天气 API
- JS 中已拆出 dailySigns / signDetails / weatherRoasts / moneyTips / doItems / dontItems / foods / places / avoidPeople / extraRoasts 共 10 个内容数组，每个 ≥10 条

## 产出文件
1. `本地测试-茂名今日签.html` — 主页面，双击打开
2. `打开今日签预览.bat` — 一键打开预览页
3. `_ai交接/2026-05-21-茂名今日签预览/交接总结.md` — 本文件

## 打开方式
- 方式 1：双击 `打开今日签预览.bat`
- 方式 2：双击 `本地测试-茂名今日签.html`

## 设计取舍
- 天气不接真实 API，用日期 seed 取模 5 种状态，保证同一天所有人看到相同天气嘴替
- 指数星数、宜忌内容、幸运信息均由日期 seed 伪随机生成，不存储任何数据
- 「换个嘴替」只更换天气嘴替文案 + 一条 extraRoast，不改变今日签主体
- 三个测试入口按钮仅为视觉占位，点击弹出「即将上线」toast
- 不接后端、不接数据库、不上线、不修改 index.html

### 第 3 轮
**新增：个人化输入层**
- 标题区下方新增表单卡片，输入项：星座（13 选项）、身份（4+暂不填）、今日状态（5+暂不填）、性别（2+不想说）、出生日期（date input）
- 「生成我的今日签」按钮触发重新计算

**personalSeed 计算方式：**
- 基值 = daySeed（日期间稳定）
- 星座权重：index × 7（不填跳过）
- 身份权重：(index + 1) × 113
- 状态权重：(index + 1) × 337
- 性别权重：(index + 1) × 997
- 出生日期权重：年×3 + 月×17 + 日×53
- 不填任何项时 = daySeed，页面不变

**生成后变化的模块：**
- 今日签文案 + signDetail
- 三个指数（搞钱/人缘/出门）
- 今日宜忌
- 开运食物 / 幸运地点 / 避雷对象
- 最近茂名风向（按身份/状态优先排序）
- 天气嘴替（跟着 seed 变化）

**风向优先规则：**
- 学生→学生宿舍、商圈奶茶优先
- 打工人→打工摸鱼、搞钱焦虑、熟人亲戚优先
- 自由搞钱→搞钱焦虑、商圈奶茶优先
- 暂时躺平→天气暴击、学生宿舍、熟人亲戚优先
- 状态叠加：想搞钱/想躺平/想出门/想避人/想恋爱 各有对应优先类别

**JS 重构：**
- 提取 `renderAll(seed, identity, mood)` 统一渲染函数
- IIFE init 调用 `renderAll(daySeed, '', '')` 保持默认行为
- `generateMySign()` 计算 personalSeed 后调用 renderAll
- `window.renderTrends` 暴露到全局，供展开/收起按钮调用
- `newRoast()` 改用 `currentSeed` 保持与当前种子一致

**验证方式：**
- 不填任何信息 → 页面正常显示默认内容
- 填写星座+身份+状态 → 点击生成 → 结果变化
- 同一组参数刷新后再次生成 → 结果一致
- 选「学生」→ 趋势卡片优先显示学生宿舍/商圈奶茶
- 选「打工人+想搞钱」→ 趋势优先打工摸鱼/搞钱焦虑

**剩余问题：**
- 「测我今年靠什么翻身」「测谁最容易拿捏我」仍为占位按钮
- 未存储到 localStorage，刷新后表单清空
- 未部署线上版本

### 第 6 轮（茂名新鲜事）
**为什么这样改：**
- 为首页增加时效感和本地生活感，让用户觉得"这个页面每天不一样"
- 先用模拟事件池验证内容节奏和视觉观感，不等真实数据源

**修改内容：**
- 新增 `localFreshNews` 数组，24 条，分 6 类（商圈人流/天气路况/店铺爆火/饭局人情/学生打工/搞钱消费），各 4 条
- 每条包含：标签（彩色徽章）、标题、本地观察、吐槽、🔥 热度（1-5）、状态（今日/近几天/本周）
- 模块位置：主卡和底部栏之间，横向滑动卡片，默认 3 条
- 「换一批新鲜事」按钮：全局种子 +1，重新随机抽 3 条
- 同一天默认第一批固定（基于 daySeed）
- 每条卡片可点击：弹出详情面板，显示完整标题/观察文字/吐槽反应，← 返回

**放弃了什么：**
- 暂不接真实新闻/API/公众号爬取

**风险/回退点：**
- 模拟内容可能不够真实，可通过替换数组快速迭代文案
- 如用户觉得像"造新闻"，可降级为"本地观察"或隐藏模块

**如何验证：**
- 主卡下方出现横向滑动卡片，默认 3 条可左右滑
- 「换一批新鲜事」点击后内容变化
- 点击单条卡片弹出详情，← 返回关闭
- 不影响个人化今日签

- 「换嘴替」从底部移入今日签主卡内，改为小按钮（🔄 换句嘴替）
- 隐藏今日幸运入口（不再显示开运食物/幸运地点/避雷对象）
- 隐藏茂名风向入口（localTrends 数据保留在代码中，后续可作测试题素材）

**放弃了什么：**

### 第 8 轮（每日状态打卡）
**为什么这样改：**
- 给首页增加每日可点击的小互动，创造复访理由（连续打卡、称号升级）
- 用轻量打卡行为替代原本运势类内容，降低"被建议"感

**修改内容：**
- 新增每日状态打卡模块，位于主卡下方、新鲜事上方
- 6 个状态胶囊按钮：空调续命 / 奶茶回血 / 打工假笑 / 想去海边 / 只想躺平 / 被亲戚问懵
- 点击状态即完成打卡，显示：今日状态、连续天数、称号、茂名精神浓度（50-99%）、嘴替文案
- 同一天可切换状态，连续天数不重复增加；隔天打卡 streak+1；中断超 1 天重置为 1
- localStorage 保存：lastDate / streak / status / history（最近 7 天）
- 称号体系：1天路过茂名人 / 3天糖水回血者 / 7天年例观察员 / 14天本地嘴替 / 30天茂名精神股东
- 每个状态至少 5 条嘴替文案，日期 seed 稳定生成
- 刷新后自动显示今日已打卡状态

**放弃了什么：**
- 不做排行榜、不做分享图生成、不做打卡提醒推送

**风险/回退点：**
- localStorage 清理后记录丢失；可后续加后端同步
- 连续天数逻辑简单，不处理跨月/跨年边界情况（已用数字 key 处理）
- 如果用户觉得打卡太像任务，可降级为纯展示

**如何验证：**
- 点一个状态胶囊 → 出现打卡结果区
- 刷新页面 → 状态保留，连续天数不变
- 同一天换状态 → streak 不变，状态更新
- 5 条嘴替文案不同

**剩余问题：**
- 未做分享功能
- 未做打卡历史日历视图

### 第 9 轮（删除打卡、前置测试入口、压缩主卡）
**为什么这样改：**
- 状态打卡是用户自报心情，不是测算结果，且占用首屏黄金位置
- 本轮把首页主轴拉回测试入口——测试是传播核心，应该在首屏能被看到
- 主卡内容（指数、宜忌）在移动端价值感不够，压缩释放空间

**修改内容：**
- 删除「今天你是什么茂名状态？」整个打卡模块（HTML + initCheckin 调用；JS 数据保留备用）
- 测试入口四宫格从底部移到主卡下方、新鲜事上方
- 首个入口改为「茂名人格测试 · 已上线」，点击跳转 index.html；其余三个仍为占位
- 今日签主卡压缩：移除指数星星行、宜忌行；换句嘴替缩成天气条右侧小按钮
- 茂名新鲜事保留，位于测试入口下方

**放弃了什么：**
- 暂时放弃每日状态打卡、连续打卡天数、称号体系、精神浓度

**风险/回退点：**
- 少了一个每日互动点；如果后续需要复访机制，可重新设计为「自动测出的每日状态」而非用户自选
- 测试入口三个占位按钮短期可能显得空，但可用「即将上线」toast 保持期待感

**如何验证：**
- 页面不再出现「今天你是什么茂名状态？」
- 首屏能看到 4 个测试入口（至少 2 个在手机上可见）
- 「茂名人格测试」点击跳转 index.html
- 茂名新鲜事仍保留但不在首屏
- 主卡明显更短（无指数/宜忌行）

**剩余问题：**
- 饭局人格、拿捏测试、搞钱命格三个入口未实现
